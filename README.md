# 央视官方直播导航（Android TV）

这是一个全屏、遥控器优先的 Android TV 网页导航器。启动时加载央视官网直播页；按遥控器 **上/下** 在预置的央视官方频道网页之间切换。

## 合规边界

- 频道列表仅保存央视官网页面 URL，不保存或提取任何直播流地址。
- 应用不提供代理、录制、缓存、转发、去广告、DRM 绕过或内容修改功能。
- 实际播放、登录、鉴权、广告与内容规则由央视官方网页控制。

## 构建

用 Android Studio 打开 `android-tv-browser`，等待 Gradle 同步后运行到 Android TV/盒子。该工作区没有 Gradle Wrapper；如本机未安装 Gradle，请用 Android Studio 创建/下载 Wrapper 后再构建。

## 使用

- 启动：默认加载 CCTV-9 纪录官方直播页。
- 遥控器上/下：循环切换官方频道网页。
- 遥控器确定键：焦点优先交给官方播放器；如果央视播放器支持遥控器全屏，会由其自身进入全屏，应用会保留该全屏画面。
- 遥控器菜单键：显示当前频道名称和切台提示；不会离开应用或调用系统浏览器。
- 系统返回键：由网页或系统处理。

当前频道目录收录央视官网“直播大全”页面展示的 20 个独立央视直播频道（含 CCTV-4 亚洲、欧洲、美洲版）。

本应用不模拟点击跨域播放器控件。是否可用确定键进入播放器全屏，取决于目标盒子 WebView 与央视官方播放器本身的遥控器支持，需在盒子真机测试。

频道名与官方网址集中在 `app/src/main/java/com/example/cctvofficialnavigator/ChannelCatalog.java`，调整时请保持为官方域名。
